# Sidekick community catalogue

Reusable instructions and visual workflows for Sidekick by Retvest. Browse the
versioned packages in [catalogue.json](catalogue.json). The initial catalogue
contains two instruction skills and a two-step briefing/review workflow.

The app-side catalogue is implemented in unreleased private source. The current
public `0.16.2-preview.2` installers do not include that integration. These
packages are untested examples, not a claim of installed functionality or quality.

The catalogue uses the existing GitHub repository. Reading it needs no Sidekick
subscription or new hosting account. Running a workflow uses your selected model;
third-party cloud providers can charge independently.

In a compatible Sidekick version, Settings → Community lets you search, inspect
the exact package and import it for manual use. Importing never runs code or
automatically enables instructions. There are no automatic package updates.

An entry's SHA-256 fingerprint binds its exact file bytes to the catalogue entry.
It does not prove the author is trustworthy, certify safety, or protect against
replacement of both the catalogue and package. Keep the version and digest when
reviewing a contribution. Source history is retained in GitHub.

[Contribute a skill or workflow](CONTRIBUTING.md). Contributions are reviewed as
pull requests before inclusion. No automated publication, ranking, ratings,
moderation service or safety certification is provided.
